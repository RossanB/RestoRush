WEB BUILD FILES

This folder contains the exported HTML5 version of Restaurant Rush.

Files included:
- index.html: Main HTML file
- Restaurant Rush.pck: Game data package
- Restaurant Rush.js: JavaScript runtime
- Restaurant Rush.wasm: WebAssembly binary
- Restaurant Rush.png: Game icon
- Restaurant Rush.icon.png: Favicon
- Restaurant Rush.apple-touch-icon.png: iOS icon
- Restaurant Rush.audio.position.worklet.js: Audio worklet
- Restaurant Rush.audio.worklet.js: Audio worklet

To play the game, open index.html in a web browser or deploy to a web hosting service.
